---

Pedro Pathing is a **path following library** developed to revolutionize autonomous navigation in robotics.

Pedro Pathing uses GVF-based feedforward + feedback control; a time-independent formulation, directly accounting for loop time-based lag; and a brake profile based on identified system dynamics for faster and more accurate autonomous routines.

Using Pedro Pathing for your autonomous routines allows for:

- **Faster path execution:** Driving speed and correction prioritization is optimized for speed and accuracy.
- **Correction for disturbances:** Correction for disturbances swiftly returns the robot to the path after disruptions.
- **Creating paths on-the-fly:** Dynamic path creation enables adaptive pathing in real time.
- **Visual path generation:** Our visualizer allows for quick and intuitive path generation from simple lines to complex Bézier curves.

Whether you are a rookie team looking for a simple and intuitive pathing library or a veteran team looking for faster autos, Pedro Pathing has the tools to build fast and reliable routines easily.
